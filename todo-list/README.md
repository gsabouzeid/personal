# Testing todo-list

## Selenium

To run Selenium E2E tests, run:

```
yarn test selenium/
```

To test coverage, run:

```
yarn coverage selenium/
```

## Cypress

To run Cypress E2E tests, run:

```
yarn cy
```

This will open the Cypress UI.
Click "E2E Testing" tab.
Select Browser of choice.
You may run tests individually, or run all of the tests.

## Playwright

To run Playwright E2E tests, run:

```
yarn pw
```

This will open the Playwright UI.
You may run tests individually, or run all of the tests.
